# Code Format

生成或修改代码前，先读取项目格式配置和相邻代码，沿用仓库已有规则。

优先级：

1. 项目 formatter、lint 和 editor 配置
2. 项目相邻文件已经采用的写法
3. 当前语言和框架的通用规范

执行原则：

- 先找配置，再生成代码；不要凭个人习惯覆盖项目规则。
- 保持生成代码的缩进、换行、括号、命名、导入顺序和文件组织与项目一致。
- 优先沿用项目已有 formatter 和 lint 的约定，但本 Skill 不执行 formatter。
- 只约束本次生成或用户明确要求修改的内容，不主动扫描或修改其他已有文件。
- 如果没有找到配置，说明采用语言默认规范，不要虚构项目规则。
